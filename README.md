# strength-training

Notes on muscle group-to-exercise mapping. I have been changing my workouts too frequently. This is an attempt to become more systematic with my strength training.

| Muscle group | Exercises | Home equivalent (where needed) |
| --- | --- | --- |
| **Chest — Mid/General** | Flat bench press, chest fly, push-ups | — |
| **Chest — Upper** | Incline bench press, incline fly | Standard push-ups (until feet-elevated push-ups are manageable) |
| **Chest — Lower** | Chest-focused dips, decline press | Standard push-ups (general chest alternative) |
| **Back — Vertical Pull** | Pull-ups, lat pulldowns | Dumbbell pullover + one-arm row (partial substitute); resistance-band lat pulldown if available |
| **Back — Horizontal Pull** | Dumbbell rows | — |
| **Shoulders — Front Delts** | Overhead press, bench press | — |
| **Shoulders — Side Delts** | Lateral raises | — |
| **Shoulders — Rear Delts** | Reverse fly, rear-delt row | — |
| **Biceps** | Biceps curls, hammer curls | — |
| **Triceps** | Overhead triceps extension | — |
| **Quads** | Squats, lunges, leg press | Dumbbell goblet squats or Bulgarian split squats (for leg press) |
| **Hamstrings — Knee Flexion** | Leg curl | — |
| **Hamstrings — Hip Extension** | Romanian deadlift | — |
| **Glutes** | Squats, deadlifts, lunges, hip thrusts | Dumbbell glute bridge (for hip thrust) |
| **Calves** | Standing and seated calf raises | — |
| **Core** | Crunches, leg raises, planks | — |
